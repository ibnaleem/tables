Source definitions retrieved **7 October 2026**. See [README.md](README.md) for
installation, exact coverage and limitations. Each catalog name below links to
its Microsoft source. The arrows link directly to the appropriate table files.

## Result of the previous missing-layout audit

All **193 entries previously marked “No named coverage”** are now resolved
within the defined base/Shift scope:

| Resolution | Entries |
| --- | ---: |
| Key-position conversion available in both directions | 178 |
| US-identical visible key characters; composition tables supplied | 8 |
| US-identical in the reviewed diagram states; no conversion file required | 7 |

The composition-only entries from that earlier missing list are:
Greek Latin, Igbo, Latvian (Standard), Maori, NZ Aotearoa, Sesotho sa Leboa, Setswana, Yoruba.

The seven entries needing no table in this scope are:
English (India), Hausa, Japanese, Korean, Latvian (QWERTY), Romanian (Programmers), Tamil Anjal.
This does not imply identical AltGr layers or input engines. Japanese/Korean IMEs
and Tamil Anjal's contextual input behavior are **not** modeled by ASCII identity.

The full catalog includes the previously covered families and the earlier
Bulgarian/Dutch additions, giving one consistent index of **218 entries**.
It uses **488 table files**: 352 key-position files and 136 common-composition
files. Exact-definition aliases share files. There are 184 unique recorded
definitions and 34 alias entries.

## Read the scope column

- **Outputs** is the number of diagram cells with a recorded output, out of 98
  (49 physical positions × base/Shift). Blank/nonprinting cells are omitted.
- **Dead** counts dead-key states. Key-position mode treats their legends as
  spacing tokens; choose a composition file for supported two-key combinations.
- **Multi** counts keys emitting more than one Unicode character.
- **Alias** gives the canonical KLID whose files are reused.
- **Outside** counts documented compositions needing a base unavailable directly
  in the reviewed states; these are retained in `index.json` but not fabricated.

No row means complete IME support or all modifier layers. No new Windows catalog
name remains unaccounted for, but AltGr/Caps Lock/keypad, extra hardware keys,
arbitrary dead-key state, Linux and macOS remain outside this package.
